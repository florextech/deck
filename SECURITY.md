# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately via GitHub Security Advisories or email.

**Do not open a public issue for security vulnerabilities.**

## Important Notes

- Deck executes commands on your PC. Only run it on trusted networks.
- The server binds to `0.0.0.0` — anyone on your local network can access it.
- Do not expose port 4000 to the internet without authentication.
